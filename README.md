# G検定 完全対策マスター（スタンドアローン版）

JDLA G検定（ジェネラリスト検定）の合格を目指すための、完全スタンドアローン型学習システムです。

## 特徴
1. **完全スタンドアローン & ゼロ依存**
   - Python 3 標準ライブラリのみで動作します（`pip install` 等の追加インストールは一切不要）。
   - 既存の開発環境や運用中アプリに一切干渉しません。
2. **未使用ポート自動バインド**
   - デフォルトポート `8765` を使用し、万が一ポートが使用中の場合でも自動的に空きポートを探索して起動します。
3. **シラバス準拠の初期マスターデータ**
   - JDLA最新シラバス全7分野の模擬問題（全選択肢の正誤理由付き解説）
   - G検定重要キーワード・最新AI用語集（重要度★付き）
4. **手打ちで問題を追加・即時反映**
   - ブラウザ上の管理画面から問題文・4択・正解・解説を入力して登録すると、ローカルの `data/questions.json` に即座に保存され、模擬試験や分野別ドリルにリアルタイムで反映されます。

---

## 起動方法

### 方法1: ワンクリック起動（Mac）
ターミナルで本フォルダに移動し、以下を実行します：
```bash
./run.sh
```
※自動的にサーバーが立ち上がり、ブラウザで `http://localhost:8765` が開きます。

### 方法2: 通常起動
```bash
python3 server.py
```
ブラウザで `http://localhost:8765` にアクセスしてください。

## 主な機能と使い方

- **⏱️ 本番形式 模擬試験**
  - 問題数（10問 / 15問 / 全問）と制限時間（あり/なし）を選択してスタート。
  - カウントダウンタイマー、見直しフラグ（🚩）、問題パレット（解答済み・未回答が一目でわかる）。
  - 終了後は合否判定（合格基準: 70%以上）、所要時間、全問題の正解・不正解・各選択肢の理由付き詳細解説を表示。
- **📚 分野別ドリル**
  - 「AIの歴史」「機械学習」「ディープラーニング」「画像認識」「NLP・生成AI」「強化学習」「法律・倫理」の各分野ごとに1問1答形式でサクサク学習。
  - 回答した瞬間に正誤判定と詳細解説が表示されます。
- **📖 重要用語集**
  - キーワード検索、分野別絞り込み、重要度（★）付き。
- **✍️ 問題の手動登録・管理**
  - 新たに入手した過去問や自作問題をフォームから入力。
  - 「登録」ボタンを押すと即座にシステムに反映。
  - 登録済み問題の検索・削除も可能です。

## ファイル構成
```
g-kentei-app/
├── server.py              # 外部依存ゼロの軽量HTTP/RESTサーバー
├── run.sh                 # ワンクリック起動スクリプト
├── README.md              # 本書
├── data/
│   ├── categories.json    # 分野定義
│   ├── questions.json     # 問題・解説データ（手動追加分もここに保存）
│   └── terms.json         # 重要用語集データ
└── public/
    ├── index.html         # メイン画面（模試・ドリル・用語集・管理）
    ├── app.js             # 学習・採点・手動登録ロジック
    └── style.css          # モダン・レスポンシブデザイン
```
